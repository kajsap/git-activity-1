# git-activity-1

# About 

Answer all 5 questions, this is to practice to navigate around your terminal and using the simple git commands (add, commit, push and clone).
In the actions sections there will be a workflow which will show you if you got the question right or wrong. The aim of this activity is to understand about the basic git commands! 

# Instructions 

- Fork this repository
- Actions -> Press "I understand my workflows, go ahead and enable them” / Enable Actions
- git clone <https URL>
- Use cd and ls to find the questions
- To open the text file:
  - Windows: start <filename.txt>
  - Mac: open <filename.txt>
  - Linux: cat <filename.txt>
- Add you answer to the text file and save
- git add <filename.txt>
- git commit -m "answer question (num)"
- git push
